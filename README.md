# \# 🤖 AI Interview Coach

# 

# A smart web application that analyzes your \*\*facial expressions, eye contact, and confidence level\*\* during mock interviews using \*\*AI + Computer Vision\*\*.

# 

# \## 🚀 Features

# \- Real-time emotion detection using FER and OpenCV

# \- Eye contact and smile tracking

# \- Confidence scoring with feedback

# \- Flask-based backend + MySQL integration

# \- Future scope: voice tone analysis, question feedback, and scoring dashboard

# 

# \## 🛠️ Tech Stack

# \- \*\*Backend:\*\* Python (Flask)

# \- \*\*AI/ML:\*\* TensorFlow, FER, OpenCV

# \- \*\*Database:\*\* MySQL

# \- \*\*Frontend:\*\* HTML/CSS/JS (optional)

# \- \*\*Deployment:\*\* GitHub / Render / AWS
